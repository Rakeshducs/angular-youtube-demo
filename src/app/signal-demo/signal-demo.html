📚 What are Inputs and Outputs?

📥 Inputs (Parent → Child)

Data flows FROM parent component TO child component

Example: Parent sends title, count, and user data to child

💡 Think of it like: Passing props to a function

📤 Outputs (Child → Parent)

Events flow FROM child component TO parent component

Example: Child sends button clicks, form submissions, and data changes to parent

💡 Think of it like: Returning values from a function

💻 Code Examples

Child Component (Input/Output) 

// Input signals (receive from parent)
title = input('Default Title');
count = input(0);

// Output signals (send to parent)
onValueChange = output<number>();
onUserAction = output<object>();

// Two-way binding
sliderValue = model(50);

// Emit events
triggerValueChange() {
  this.onValueChange.emit(this.count() + 1);
}

Parent Component (Usage) 

<!-- Send inputs to child -->
<app-child
  [title]="parentTitle()"
  [count]="parentCount()"
  [(value)]="parentSlider"
  (onValueChange)="handleValueChange($event)"
  (onUserAction)="handleUserAction($event)"
></app-child>

// Handle outputs from child
handleValueChange(value: number) {
  console.log('Child sent:', value);
}

🎯 Key Takeaways

📥 Inputs

  • • Parent → Child data flow
  • • Use square brackets [prop]
  • • Child receives as signals
  • • Automatic reactivity

📤 Outputs

  • • Child → Parent events
  • • Use parentheses (event)
  • • Parent handles events
  • • Custom event data

🔄 Two-Way

  • • Bidirectional flow
  • • Use [(model)] syntax
  • • Both components sync
  • • Real-time updates
